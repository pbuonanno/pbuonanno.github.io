# Paolo Buonanno — Academic Website

Personal academic website of Paolo Buonanno, University of Bergamo.

## Deploy

In GitHub, open **Settings → Pages** and select **Deploy from a branch**, **main**, **/(root)**, then **Save**. Once active, the website is served at https://pbuonanno.github.io/.

The website uses plain static `index.html`, `publications.html` and `styles.css`. No build tooling is required.

## Photo

The homepage currently links to a low-resolution 210×210 public portrait hosted by BEELAB at `https://www.unibg-beelab.it/wp-content/uploads/2021/05/paolobuonanno.jpeg`. This is a provisional external image, not a copy stored in the repository. The site is designed to work even if it fails to load. Replace it with a properly licensed and suitably high-resolution photograph stored in the repository (e.g. `assets/portrait.jpg`) when available.

## Important editorial checks

Verify the current states of manuscript submissions, revise-and-resubmits and conditional acceptances. These have been migrated from an older public version of the academic website. Some older journal entries do not yet link to DOIs in the GitHub edition, although the complete offline archive contains more identifiers. Check the CV link and the 2026/27 teaching entries. The original Google Sites website remains unchanged.
